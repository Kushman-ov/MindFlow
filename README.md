# MindFlow — личный ежедневный планировщик

Рабочий стартовый веб-проект на React + Vite. Он не требует платных API и хранит данные локально в браузере.

## Возможности
- Ежедневная отметка энергии, настроения и доступного времени.
- Добавление, редактирование, выполнение и удаление задач.
- Приоритеты, категории и длительность задач.
- Локальный алгоритм формирования плана с главным приоритетом и задачами «на потом».
- Фокус-таймер на 15 минут с паузой и сбросом.
- Итоги дня и сохранение заметки.
- Автоматическое сохранение состояния в localStorage.
- Адаптивная верстка для телефона и компьютера.

## Требования
Установленный Node.js LTS (npm входит в установку). Интернет нужен при первой установке зависимостей. После установки само приложение работает локально без ИИ API.

## Запуск с нуля
1. Установи Node.js LTS с https://nodejs.org/.
2. Распакуй архив `mindflow.zip` в папку.
3. Открой терминал в папке `mindflow`.
4. Выполни:

   ```bash
   npm install
   npm run dev
   ```

5. Открой адрес, который покажет Vite, обычно `http://localhost:5173`.
6. Чтобы остановить сервер, нажми `Ctrl+C` в терминале.

## Проверка production-сборки

```bash
npm run build
npm run preview
```

## Проверочные сценарии
1. Добавь задачу «Оплатить интернет», длительность 5 минут, приоритет «Срочно». Она появляется в списке.
2. Обнови страницу. Задача остаётся — сохранение работает.
3. Добавь ещё задачи, суммарно превышающие доступное время. Нажми «Составить план дня»: часть задач попадёт в «на потом».
4. Выставь энергию «На нуле» и составь план: появляется мягкая рекомендация не перегружать день.
5. Отметь задачу выполненной: счётчик прогресса обновляется.
6. Отредактируй задачу и удали другую.
7. Запусти фокус-таймер, поставь на паузу и сбрось.
8. В «Итогах» сохрани заметку и обнови страницу.
9. Проверь ширину мобильного экрана через инструменты разработчика браузера или открой на телефоне по локальной сети.

## Важные ограничения первой версии
- Планирование выполняется прозрачным локальным алгоритмом, а не языковой моделью. Это позволяет держать бюджет в 0 ₽ и работать без API-ключа.
- Данные хранятся в localStorage конкретного браузера и устройства. Очистка данных браузера может удалить их; облачной синхронизации нет.
- При смене даты задачи остаются в общем списке, но план дня и оценка состояния сбрасываются. Перед полноценным использованием добавь экспорт/резервное копирование.
- Это локальный MVP без аккаунтов, уведомлений и синхронизации.
